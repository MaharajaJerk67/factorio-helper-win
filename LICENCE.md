## 🧩 About

**Factorio Helper** is a curated list of Factorio open-source tools:

- **Mod Menus** — inventory editor, speed control, instant crafting, research unlocker, free camera
- **UI Automation Bots** — resource scanner, auto-miner, blueprint manager, input helpers for single-player study
- **Quality-of-Life Mods** — quick bar enhancer, logistics overlay, crafting queue manager, map reveal
- **Research Frameworks** — factory layout optimizers, production calculators, config notes for educational use

Based on publicly available community tools like **Factorio Mod Portal**, **Factorio Companion**, and **QOLMod**.
